# The Java Programming Language

**Java** is a versatile programming language used to build everything from small applications to complex distributed systems.

This guide groups Java fundamentals into the following topics:

1. **Java Core** — data types, keywords, operators, and objects: the foundations for the other topics.
2. **Collections** — data structures and interfaces for storing and managing groups of objects, including lists, sets, and maps.
3. **Exceptions** — mechanisms for handling errors and making application behavior more reliable and maintainable.
4. **Generics** — type-safe classes and methods that reduce runtime type errors and improve flexibility.
5. **Functional Interfaces** — interfaces that work with lambda expressions to express behavior concisely.
6. **Stream API** — processing pipelines for filtering, sorting, transforming, and aggregating data.
7. **Multithreading** — thread management, synchronization, and thread safety for concurrent tasks.
8. **Object-Oriented Programming** — encapsulation, inheritance, polymorphism, and abstraction.

Each topic helps you understand and write maintainable Java applications.
